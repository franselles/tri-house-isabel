
# Residencial Isabel

Landing page de Residencial Isabel, un proyecto residencial que busca conocer las preferencias y necesidades de sus futuros clientes mediante una encuesta.

La web presenta el proyecto y permite a las personas interesadas compartir sus preferencias sobre las características de la futura vivienda, ayudando a orientar el desarrollo del proyecto.

## Tecnologías

- Nuxt.js
- Tailwind CSS

## Funcionalidades

- Presentación del proyecto residencial.
- Encuesta para conocer las preferencias de los futuros clientes.
- Recogida de respuestas mediante Google Sheets.
- Páginas informativas de aviso legal, privacidad y cookies.

## Estado del proyecto

En desarrollo. La web y sus contenidos podrán evolucionar a medida que avance el proyecto residencial.
